    How to play

    • There is no time limit. The clock only shows how long you have played, and it stops while this notebook is open.
    • Papers: select one to read it up close. Esc or the close button puts it back.
    • Combination locks: take the clues in order; the codes they point to, in that order, open the lock. Set each dial with the arrows above and below it or the arrow keys, or type the whole code in the box labelled “Type the whole code instead”. Then press “Pull the shackle”.
    • Other locks: press the button named on the handle’s tag (“Check answers”, “Check order” or “Submit”).
    • Every room has a Describe this room button. It lists everything in the room as text.
    • Every sound comes with a message on screen, so the game plays the same with sound off.
